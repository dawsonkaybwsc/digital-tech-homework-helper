# Digital Tech Homework Helper

Go to https://github.com/dawsonkaybwsc/digital-tech-homework-helper
<br>
Click the green Code button, then Download ZIP.
<br>
<img width="441" height="421" alt="Screen Shot 2026-10-16 at 1 46 53 PM" src="https://github.com/user-attachments/assets/2ad00427-740a-42a4-9b96-25c26517f317" />
<br>
Find the ZIP in your downloads folder, right click it and choose extract all, then click extract. Don’t run it from inside the ZIP.
<br>
Open the extracted folder and go to HomeworkHelper -> HomeworkHelper -> bin → Debug -> net9.0-windows.
<br>
Double click the HomeworkHelper.exe
<br>
If windows shows “Windows protected your PC”, click More info, then Run anyway. This appears because the app isn’t digitally signed.

If the app doesn't open install the .NET 9 Desktop Runtime if you don’t have it. Go to [.NET 9 Desktop Runtime](https://dotnet.microsoft.com/download/dotnet/9.0), find .NET Desktop Runtime, and download the x64 Windows installer. Run it.

<img width="681" height="334" alt="Screen Shot 2026-10-16 at 2 03 11 PM" src="https://github.com/user-attachments/assets/07e633fe-b126-4648-b5d8-1a7e0d55126d" />

If the application still won't open, make sure you have **.NET Framework**, **DirectX**, and **Microsoft Visual C++ Redistributable** installed.

Download the [Visual C++ Redistributable All-in-One package](https://www.techpowerup.com/download/visual-c-redistributable-runtime-package-all-in-one/), extract it, and run `install-all.bat`. The install process should take only about 5 minutes.

<img width="384" height="259" alt="Screen Shot 2026-10-16 at 9 07 29 AM" src="https://github.com/user-attachments/assets/b3a527ad-6df1-43df-a5f0-0a2062b3f1b2" />


After installing everything, try opening the application again.
(This application is only supported on windows base computers)
