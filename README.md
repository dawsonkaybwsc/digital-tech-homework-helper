# Digital Tech Homework Helper

If the application won't open, make sure you have the **.NET Framework**, **DirectX**, and **Microsoft Visual C++ Redistributable** installed.

Download the [Visual C++ Redistributable All-in-One package](https://www.techpowerup.com/download/visual-c-redistributable-runtime-package-all-in-one/), extract it, and run `install-all.bat`.

<img width="384" alt="Installation instructions screenshot" src="https://github.com/user-attachments/assets/e1873608-cbf6-425a-8023-508861dc3a3f" />

After installing everything, try opening the application again.
